# UI image provenance

- **`app_icon.png`, `app_icon_360.png`** (the game's app icon: a cartoon treasure chest with two big eyes on its lid, gold coins, a gold chain and a padlock).
  - Owner-supplied, 2026-11-13: the owner sent this picture to replace the chest picture supplied on 2026-11-08 (a 980 x 980 WebP, SHA-256 `9866388c6d11d101a6e17681cfb081a2cef5ab60a44e1332f17e129af578dfb9`), which had been the icon since then. The original is an 864 x 864 PNG with a transparent background, SHA-256 `bfeaff67c6f2c1de376b0a50b02bfdad438f82539b8cf9ec9dd790d4fcc55e6c`. Neither original is kept in the repo.
  - `tools/make_app_icon.sh <original>` makes `app_icon.png`, the master: the picture unscaled, centred on a transparent 968 x 968 square, its visible pixels unchanged. The chest nearly fills the picture, so the square is tighter than the 1024 the old picture had; the chest covers as much of each icon as the old one did. From the master it makes `app_icon_360.png` with Lanczos, keeping the outline's anti-aliased edge; every pixel of it under 20/255 alpha is black, as every fully transparent pixel of the master is. Both imports keep `process/fix_alpha_border` off, so the game and the exports use those pixels as they are (`game/tests/headless_world_material_contract.gd` checks it).
  - The committed `app_icon.png` is the source of truth: `tools/make_app_icon.sh` with no argument rebuilds `app_icon_360.png` from it.
  - Used as the macOS app icon (`export_presets.cfg` `application/icon`, from the master) and as `application/config/icon` (the 360 version): the Linux window icon, the web favicon (which the web page's loading screen shows too) and the web's 180 x 180 apple-touch-icon. The 360 version is also the chest on the game's loading screen (`game/scenes/ui/hud.tscn`).
- **`touch/icon-car.png`, `touch/icon-drop.png`, `touch/icon-brake.png`** (the touch use button's icons): drawn by `tools/draw_touch_icons.sh`, which writes them into `game/resources/ui/touch/`, the same byte for byte on every run.
- The RISE and RUN button art and the stick in `selgesel/` come from the MIT Selgesel controller; see `game/scripts/vendor/selgesel/README.md`.
