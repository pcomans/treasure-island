  ten unique files, not eleven. The three additional files contain no private

  files. Capture-time hashes remain capture-time hashes; the current sanitized
  hashes are separate. No retained image, motion frame, visual verdict, or

  occurrences. D1 Building 201, D1 Building 225, and Dormitory 369 remain

- **No blocking discrepancy found.** Two nonblocking items are ranked below:

The PCK contains all 143 source test script names as 143 compiled `.gdc`
resources plus 143 remaps: 286 of 850 entries, 2,102,696 stored bytes, or
3.2219% of the PCK. It contains no test `.gd`, UID, README, image, movie, or
other media payload.

Only six support helpers are required by production facade preloads. Their six
compiled resources plus six remaps total 66,692 bytes, or 0.1022% of the PCK.
Decompressed inspection of all six found zero private path, URL,
discovery/evidence/source-assets, image, source-photo, or provenance locator.
Three use a facade-coverage identifier containing the word `pixels`; that
identifier describes generated receiver coverage and is not stored source
photography.

The other 137 compiled test scripts plus remaps total 2,036,004 bytes. Their
decompressed bytecode contains no concrete workstation identity/path and no
media, but it does expose internal test metadata:

- 115 compiled tests contain one or more discovery/evidence/source-assets
  literal;
- three complete URLs remain: two public NPS authority URLs and one deliberate
  invalid-domain fixture;
- several tests contain bare `/Users/`, `/Volumes/`, file-URL, and HTTP(S)
  negative-test sentinels.

This is therefore more precise than calling the residue either a source-pixel
leak or pure binary bulk. It is **not** a privacy, source-photo, authoring-root,
or normal-runtime leak, and the main scene executes none of the tests. It is a
nonblocking internal-metadata disclosure and package-footprint issue under the
present private, explicitly scoped milestone. A future policy requiring no
recoverable source URLs or test locators anywhere in decompressed container
bytes would fail until the six clean helpers move to a runtime namespace and
the remaining test tree is excluded.

The implementer's final boundary section already disclaims a whole-container
forbidden-word assertion. Its earlier phrase that external URLs “live only” in
the source receipt must consequently be read as applying to the migrated
seven-config provenance cohort, not every compiled test byte.
