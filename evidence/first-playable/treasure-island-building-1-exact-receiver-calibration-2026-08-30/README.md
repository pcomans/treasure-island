# Building 1 detached exact-receiver calibration evidence

This directory is the native Godot 4.7.2 Forward+/Metal proof for a detached, review-only Building 1 calibration. It is not attached to the live receiver and is not an art-acceptance or lifecycle-promotion record.

## Exact scope

- `B1-MAT-IVORY`: outer runs `21..51`, 31 runs, `85.939934 m`, `1740.731069 m²` generated mesh surface area.
- UV convention: `UV.x` is cumulative horizontal chain metres from run 21; `UV.y` is source world Y metres. All 30 joins have zero endpoint and chain-phase delta in the registry/helper proof.
- Material scales: `1.10 m` primary and `0.32 m` secondary; these remain reference-derived production inference, not survey measurements.
- `FIT-CENTRAL-W-R36`: complete CENTRAL module at the deterministic run-36 midpoint, a contact/scale study only.
- `FIT-PAV-W-R06`: complete PAV module at the deterministic longest-safe north-end candidate run midpoint, a contact/scale study only.

The two studies authorize no actual-world anchor, count, cadence, sequence, receiver integration, complete elevation or whole-building claim. `B1-WING-W`, `B1-BASE-O`, `B1-DOOR-BLUE` and `B1-BAND` are checksum-locked but absent.

## Evidence set

The 15 PNGs are 1440×900 native macOS captures. Views 01–05 visually sample five joins; the manifest contains the complete 30-join machine proof. View 06 covers the full macro span. Views 07–12 cover complete CENTRAL/PAV close, oblique and ordinary-distance behavior. View 13 supplies multi-side/whole-building context without acceptance. Views 14–15 show changed light.

`visual-verification.json` records the executor's validity inspection and candid framing limitations. `runtime-isolation.json` pins generated/runtime, mapping, standalone and interrupted-r133351 bytes. `capture-manifest.json` records camera, renderer, transforms, full fit-study metadata and image hashes. `checksums.sha256` seals the review package.

## Review boundary

An independent reviewer may judge only:

1. MAT-IVORY physical scale, phase continuity and macro behavior on exact runs 21..51.
2. CENTRAL-W scale/contact fitness on representative run 36.
3. PAV-W scale/contact fitness on representative run 6.
4. Whether the evidence is sufficient for a later, separately authorized calibration verdict.

No live placement, cadence, real coordinate, surveyed scale, completed elevation, or whole-building claim is presented.
