# Grand Treasure Island: what changed in each build

Every build of the game has a number, the one in its title on the [releases page](https://github.com/pcomans/treasure-island/releases) and in its version on [itch.io](https://phppco.itch.io/grand-treasure-island). Its entry here says what changed for players, newest build first; an entry's number is the build it was written for, and the release that first carries it may have a slightly larger one. For each build after 2084, the release's notes start with its changes, and its itch.io downloads carry them as `CHANGELOG.txt`.

## Build 2144 (2026-11-16)

- On the web, the game's data is kept on your device after the first visit, so later launches skip the big download until a new build is out. Not yet on iPhone and iPad.
- On the web, the loading line says whether the game is downloading or loading from your device.
- Web: less memory churn from sound while you play.

## Build 2117 (2026-11-16)

- The release notes on GitHub and the itch.io downloads now say what changed in each build.
- The pause menu shows the build number.
- On an iPhone or iPad, the start screen says how to add the game to the home screen for full screen, and that silent mode must be off to hear sound.
- Added to a phone's home screen, the game opens full screen, like an app.
- On an Android phone or tablet, tapping to play also makes the game full screen.
- The Mac app has been signed and notarized by Apple since build 2084.

## Build 2084 (2026-11-16)

- The park outside Isle House is in: lawn, chip beds, young pines, timber benches, chairs and logs, with a grass bank beside Avenue of the Palms.
- In Options, the time-of-day slider marks sunrise and sunset and says "Night is experimental".
- Web: reflections take about 250 MB less graphics memory, which helps on phones.

## Build 2047 (2026-11-16)

- Pelicans, cormorants and gulls rest on the breakwater.

## Build 2027 (2026-11-16)

- A Windows build (64-bit) joins the Mac and Linux builds. It loads the island on a test machine but has not yet been played on a real Windows PC.
- The downloads are named after the game and the build number.

## Build 2010 (2026-11-16)

- The game is now called Grand Treasure Island; options chosen in earlier builds carry over.
- The glare of a low sun on glass is back.
- The loading screen names each step as it runs.
- Play starts at 12:30 on the island's date, whatever the real time.

## Build 1962 (2026-11-16)

- No changes to the game.

## Build 1933 (2026-11-16)

- No changes to the game.
