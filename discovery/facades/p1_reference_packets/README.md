sources while preserving the frozen project receiver contract. They supplement,
but do not replace, the earlier detailed reference specifications and accepted
evidence. Claims use four labels:

- `verified_fact`: explicit in a project contract or authoritative primary source;
- `reference_observation`: visible in a dated, identified source;

to the repository. Architect/developer and Google imagery is observation-only.

reuse must follow the rights statement on the exact item.

## Cross-packet corrections and decisions

1. The frozen OSM `ref:nrhp=08000081` on Buildings 2 and 3 conflicts with
   authoritative National Register records. `08000081` is Building 1;
   Building 2 is `08000082`, and Building 3 is `08000083`. Preserve the frozen
   snapshot, but do not repeat its value as identity evidence.
2. The current six-story primary-source description of 490 conflicts with the
   frozen five-level/15 m receiver. The current Isle House seven-story podium
   conflicts with its five-level/15 m low part. These are massing issues, not
   texture prompts.
3. A recognition pass is allowed to use a small number of high-information,
   observed cues. It does not need to invent unknown rear/courtyard schedules.
   Unknown sides may use a conservative building-wide material family only when
   the packet explicitly permits it; unique motifs stay on observed sides.
4. No identity needs a `HUMAN.md` dependency for the first implementation batch.
   If a future acceptance gate demands surveyed, all-side, as-built layouts,
   request owner-supplied/licensed orthographic elevations for only that blocked
   unit rather than stopping the rest of the cohort.
