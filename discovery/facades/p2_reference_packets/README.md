# P2 campus/cohort reference packets

Checked: **2026-09-04**
Scope: **reference readiness only; no runtime, generator, registry, Building 1, or P1 change**

These nine packets bind public-source research to the exact frozen P2 receiver
units. They do not rewrite the source snapshot when a current address, name, use,
or lifecycle differs. Claims use the project vocabulary:

- `verified_fact`: explicit in a project contract or authoritative primary source;
- `reference_observation`: visible in a dated, identified observation source;
- `production_inference`: reversible art/implementation guidance, not an as-built claim;
- `unknown`: unsupported and excluded from implementation and acceptance.

No external image was downloaded, copied, captured, embedded, uploaded, or added
to the repository. Government, institutional, and Google imagery is linked and
used for observation only. Reuse of any source asset requires checking the rights
statement for that exact item; a government host alone does not prove that every
embedded photograph is public domain.

## Material identity corrections

1. `w34313514` cannot yet inherit a real-world name from the frozen string.
   The frozen source includes its own uncertainty note; the 1995 federal transfer
   record distinguishes culinary Building 363 from dormitory Buildings 487–489.
2. `w34313544` is one footprint, Building 450. “Naval Station Treasure Island”
   and Wikidata `Q15261196` describe the much larger former station, not this one
   building. Building 450 historically housed Twelfth Naval District functions
   and was later rehabilitated for Job Corps.
3. Building 442 has used both `655 Avenue H` and `351 H Avenue` in official DOL
   sources. The packet treats this as address/lifecycle drift, not permission to
   rewrite the frozen snapshot.
4. Building 600 likewise has a campus address (`750 Avenue M`) and an official
   public-entrance address (`649 Avenue N`, entrance on 10th Street).
5. The official record says buildings at the former Building 29 site were
   demolished in February 2024, but does not enumerate `29B`; no packet may turn
   that inference into a verified demolition claim for `w34313523`.
